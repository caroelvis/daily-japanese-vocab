# 每日日文 · Daily Japanese

純靜態日文學習網站：對齊 [每日英語單字](https://github.com/caroelvis/daily-english-vocab) 的架構（閃卡＋測驗），並加上 **基礎 50 音教學標籤**。

介面繁體中文，內容日文。可雙擊 `index.html` 開啟，也可放到 GitHub Pages。

網站：https://caroelvis.github.io/daily-japanese-vocab/

## 如何開啟

### 方法一：直接雙擊 `index.html`

用 Chrome / Edge / Safari 開啟即可。

### GitHub Pages

Settings → Pages → Deploy from branch `main` / `/ (root)`

網址：`https://caroelvis.github.io/daily-japanese-vocab/`

## 功能

### 內容：50音｜單字｜句子

- **50音**：平假名／片假名字表、閃卡、測驗。可用教學標籤篩選。
- **單字**：分類篩選、閃卡、看中文選日文。
- **句子**：學校、職場、餐廳、車站、購物、居家、醫院。

### 50音 · 教學標籤

| 標籤 | 說明 |
| --- | --- |
| 平假名／片假名 | 切換書寫系統 |
| 清音 | 基礎 46 音 |
| 濁音 | ゛：がざだば行 |
| 半濁音 | ゜：ぱ行 |
| 拗音 | い段＋ゃゅょ |
| 行 | あ行、か行… |

字表可點選單一音：大字、羅馬拼音、記憶提示、例詞與發音。

### 閃卡／測驗

- 閃卡：隨機抽題；快捷鍵 N 下一個、B／← 上一個、空白鍵發音
- 測驗：20／50／100 題；答錯可再試一次；連續錯兩次顯示正解

純靜態，無需建置。發音使用柔和的日語女聲「七海」。若音檔無法播放，會退回瀏覽器的日語語音。
